## Problem Statement

A guild is preparing for a festival, and the master wants every dragon in the stable to end up with the same amount of gold. Gold can only be added to a dragon’s hoard. None can be taken away.

There are n dragons, and the current size of the i-th dragon’s hoard is a_i coins.

Your task is to determine the minimum total number of coins the guild must spend so that all dragons have equal hoards.

## Input

```
The first line contains an integer n (1 ≤ n ≤ 100), the number of dragons.

The second line contains n integers a1, a2, ..., an, where a_i (0 ≤ a_i ≤ 10^6), the number of coins in the hoard of the i-th dragon.
```

## Output

```
Print a single integer S, the minimum total number of coins that must be added.
```

In the second example, it is enough to give 1 coin to the third dragon.

In the third example, you need to give 2 coins to the first and third dragons so that every hoard becomes 3.

In the fourth example, no coins need to be added because the only dragon already has 12 coins.
